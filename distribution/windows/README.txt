WebEngine Vehicle - Windows x64

Requires Windows 10 build 19041 or newer, an updated Direct3D 12 capable graphics
driver, and a normal interactive Windows desktop. Windows 11 is supported within
the tested scope. No browser, Python, Visual Studio or SDK is needed to play.

Extract the complete ZIP first. Double-click Install.cmd to install for the
current user without administrator rights. Launch from the Start menu, or run
WebEngineVehicle.exe directly from the extracted folder for portable use.
Uninstall through Windows Settings > Apps. Saves/settings/support logs are kept.
Close the game before upgrading, and extract new ZIPs to a different folder.

WASD/arrows drive. Space brakes. Shift handbrake. R resets.
P or Escape opens pause/settings. F11 toggles fullscreen. Quit closes the game.
Controller: left stick steering; RT/LT throttle/reverse; A/B brake/handbrake.
Start opens the menu, D-pad navigates, A confirms, B returns.

The launcher checks bundled files and dependencies. Follow its support log path
if startup fails. Logs and best-effort crash minidumps normally go to:
  %LOCALAPPDATA%\WebEngine\Vehicle\logs
Game progress/settings normally use the OS per-user WebEngine Vehicle profile.
Logs/dumps are local files, not uploaded automatically. Dumps can contain process
memory; share them only with support you trust. Keep matching symbols separately.

This development distribution is unsigned. Publisher signing, enterprise policy
acceptance, physical hardware/driver coverage and clean-VM sign-off are separate
release gates. SHA-256 checks detect incomplete/corrupt files; they do not prove
publisher identity. Third-party notices are included beside the executable.
